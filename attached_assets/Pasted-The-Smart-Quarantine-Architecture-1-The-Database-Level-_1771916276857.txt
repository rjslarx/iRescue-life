The Smart Quarantine Architecture
1. The Database Level (The Flags) You need two simple columns added to the animal's profile: a boolean (is_quarantined) and a text string (quarantine_reason).
2. The Profile Level (The Red Banner) If is_quarantined is true, the animal's profile should render a massive, unmissable red banner at the very top of the screen (above the tabs). It shouldn't just say "Quarantine"; it needs to state the reason (e.g., "⚠️ STRICT ISOLATION: Parvovirus").
3. The Execution Board Level (The Warning Icon) This is the most important part. If a volunteer is looking at the Daily Execution Board, they shouldn't have to click into the dog's profile to find out it's contagious. Any medication or task belonging to a quarantined dog must be highlighted in red or feature a biohazard icon (☣️) right there on the daily roster.

I need to implement a global "Quarantine / Isolation" safety system to prevent cross-contamination in the rescue.

1. Database Update (`animals` table):
   - Add a boolean column: `is_quarantined` (default: false).
   - Add a text column: `quarantine_reason` (nullable).
   - Add a date column: `quarantine_start_date` (nullable).

2. Animal Profile UI (The Warning Banner):
   - In the Animal Profile component, check if `is_quarantined` is true.
   - If true, render a prominent, sticky red banner at the absolute top of the profile header.
   - Use a bold icon (like a triangle alert or biohazard symbol).
   - Display the text: "⚠️ STRICT QUARANTINE: [quarantine_reason]".
   - Add a "Manage Quarantine" button inside the banner to allow staff to update the reason or clear the quarantine status.

3. The "Daily Execution Board" Integration:
   - On the `UnifiedDailyMedicalRoster` component (both the dashboard widget and the full page), we must warn volunteers before they execute tasks.
   - When fetching the daily pending tasks, join or include the animal's `is_quarantined` status.
   - IF the animal is quarantined:
     - Render their task row with a subtle red/rose background (e.g., `bg-red-50`).
     - Append a red ⚠️ or ☣️ icon next to the animal's name in the list.
