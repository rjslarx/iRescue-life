I need to build an "Inbound Veterinary Records Integration" settings UI for my tenants. Because we are bypassing standard Gmail forwarding to avoid verification codes, this UI will act as a step-by-step Setup Wizard for Google Workspace Admin routing.

1. Database Schema Check (`tenants` table):
   - Ensure the `tenants` table has a string column named `system_inbound_email`. 
   - If a tenant does not have one generated yet, it should auto-generate on page load in the format: `import-tenant-[uuid]@inbound.ourdomain.com`.

2. The UI Component (`<VetIntegrationSettings />`):
   - Create a new settings card titled "Automated Veterinary Records Import".
   - Add a brief intro: "Automatically import medical PDFs from your vet directly into your animal profiles by creating a dedicated records email address."
   
3. The "Copy Webhook" Section:
   - Display the tenant's unique `system_inbound_email` in a disabled input field.
   - Add a prominent "Copy to Clipboard" button next to it.
   - Label it: "Your System Routing Address (Keep this secret)".

4. The Step-by-Step Tutorial Accordion:
   - Below the webhook address, build a numbered list or accordion component containing the following instructions exactly as written for the user to follow:

   **Step 1: Access Google Admin**
   Log into your Google Workspace Admin Console (admin.google.com). Go to the left menu: Apps -> Google Workspace -> Gmail. Scroll down and click on "Routing".

   **Step 2: Create the Routing Rule**
   Next to "Routing" (not Default Routing), click "Configure" or "Add Another Rule". Name the rule: "Forward Vet Records to Software".

   **Step 3: Set the Trigger**
   - Under "1. Email messages to affect", check the box for **Inbound**.
   - Scroll down to "C. Envelope filter". 
   - Check **Only affect specific envelope recipients**.
   - Select **Single email address** from the dropdown.
   - Type in the public email address you want your vet to use (e.g., records@yourrescue.org).

   **Step 4: Set the Handoff Action**
   - Scroll up to "2. For the above types of messages, do the following".
   - Under "Envelope recipient", check the box for **Change envelope recipient**.
   - Select **Replace recipient**.
   - Paste your "System Routing Address" (copied from above) into the text box.

   **Step 5: Save**
   Scroll to the bottom and click **Save**. You are done! Tell your vet to email all PDFs to that public address, and they will automatically appear in your database.

5. Visual Polish:
   - Ensure the UI looks like an enterprise integration page. Use bolding for the UI elements the user needs to click in Google Workspace.
