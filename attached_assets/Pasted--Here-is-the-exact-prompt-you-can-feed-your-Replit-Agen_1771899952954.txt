
Here is the exact prompt you can feed your Replit Agent to build the Command Center Widget version of the daily roster.
This prompt specifically tells the AI to build it as a compact, dashboard-friendly component (replacing those colorful Quick Action buttons) without overloading the screen with complex filters.
Copy and paste this directly into Replit Agent:
I need to build the "Daily Execution Board" widget for the Command Center dashboard. This will replace the current "Quick Actions" button section.

Please create a component called `<DailyExecutionWidget />`.

1. Layout & Container:
   - Wrap the component in a standard Dashboard Card to match the existing UI.
   - Use a Flexbox or CSS Grid layout split into two columns: 
     - Left Column (approx 35% width): The Navigation Calendar.
     - Right Column (approx 65% width): The Action Roster.
   - Set a fixed height (e.g., `h-96` or `max-h-[400px]`) with `overflow-y-auto` on the right column so the dashboard doesn't stretch infinitely if there are 50 meds due.

2. The Mini-Calendar (Left Column):
   - Implement a small, clean month-view calendar component.
   - The calendar should default to `Today`.
   - When a user clicks a different date, update a local `selectedDate` state.

3. The Data Fetching:
   - Fetch the combined medical orders (Preventatives, Medications, Procedures, Exams, Labs) for the `selectedDate` where `status = 'pending'` or `active`.
   - Group the fetched data into three distinct arrays: 'In-House Meds', 'Vet Visits/Surgeries', and 'Labs'.

4. The Action Roster (Right Column):
   - Render the data for `selectedDate` in distinct sections.
   - Section 1: "Meds & Preventatives" -> Render as a compact list (Animal Name - Drug Name - Dose). Include a quick "Mark Given" checkbox.
   - Section 2: "Vet Visits & Surgeries" -> Render as a compact list (Animal Name - Procedure/Exam). Include a small "Log" button.
   - Section 3: "Pending Labs" -> Render as a compact list.
   - IF there are zero tasks for the selected date, display a cheerful empty state: "All caught up for this day! 🎉"

5. Dashboard Integration:
   - Import `<DailyExecutionWidget />` into the main Home/Command Center view.
   - Place it directly below the top row (Medical Pipeline / Daily Briefing) and remove the old horizontal Quick Action buttons entirely.

Why this specific prompt is safe for your UI
By explicitly telling the agent to use a fixed height with a scrollbar (overflow-y-auto) in Step 1, you protect your dashboard layout. If a rescue has a crazy day with 40 dogs needing heartworm pills, the widget won't suddenly stretch all the way down to the floor and push your Kanban board off the screen. It will stay a neat, tidy box that the staff can just scroll through.
