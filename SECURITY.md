# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in iRescue.life, please report it responsibly by emailing:

**admin@irescue.life**

Please do **not** open a public GitHub issue for security vulnerabilities, as this could put users at risk before a fix is available.

## What to Include

When reporting a vulnerability, please include:

- A description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Any suggested fixes (optional)

## Response Timeline

- We will acknowledge receipt within 48 hours
- We will provide an initial assessment within 7 days
- We will work with you to understand and resolve the issue promptly

## Scope

This security policy applies to:
- The iRescue.life platform codebase
- Official deployments at irescue.life

Third-party forks and modifications are the responsibility of their respective maintainers.

## Recognition

We appreciate responsible disclosure and may acknowledge security researchers in our release notes (with your permission).

Thank you for helping keep iRescue.life and its users safe!
