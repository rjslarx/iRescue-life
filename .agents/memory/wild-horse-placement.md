name: Haseya’s wild horse placement
description: Tenant scope and preservation rules for wild versus domesticated horse applications.
---

Haseya’s requested a separate wild horse placement application based on their four-page PDF. The existing horse application remains for domesticated horses; existing horses default to domesticated until staff deliberately mark them wild.

**Why:** Wild, unhandled horses require different safety, companionship and long-term care screening. This is Haseya’s workflow, not a change to every tenant’s horse applications.

**How to apply:** Select the form using the saved horse classification and tenant on the server. Preserve historical question meanings when forms or animal classifications change. The placement application acknowledgment is not the separate final placement agreement. Staff review remains in the existing adoption application workflow.
