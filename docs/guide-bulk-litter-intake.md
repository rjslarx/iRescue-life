# How to Use Bulk Litter Intake

Use the Bulk Litter Intake wizard to quickly add an entire litter of puppies or kittens into the system at once, instead of entering each animal one at a time.

---

## Opening the Wizard

1. Go to **Animals** from the sidebar.
2. Click the **Litter Intake** button near the top of the page.

---

## Step 1: Shared Litter Information

Everything you enter in Step 1 applies to every animal in the litter.

| Field | What to Enter |
|---|---|
| **Intake Date** | The date the litter was received (defaults to today). |
| **Intake Source** | How the litter arrived: Stray, Owner Surrender, Transfer, Born in Care, or Other. |
| **Species** | Dog or Cat. This also determines which breeds and medical protocols are available. |
| **Breed** | Select the breed from the list (updates automatically based on species). |
| **Age** | Baby, Young, Adult, or Senior. For litters this is usually "Baby." |
| **Size** | Small, Medium, Large, or X-Large. |
| **Location Type** | Where the litter will be housed: Shelter, Foster, Clinic, Transport, or Offsite. |
| **Location Name** | Optional. A specific name like a building or foster home. |
| **Mother** | Optional. If the mother is already in the system, select her here. Only eligible females are shown. |
| **Apply Protocol** | Leave this on to automatically schedule age-appropriate vaccinations, deworming, and flea/tick prevention for every animal in the litter. |

When everything looks right, click **Next: Speed Grid**.

---

## Step 2: Speed Grid (Individual Animals)

The grid starts with one empty row. Fill in the details for each animal in the litter.

| Column | What to Enter |
|---|---|
| **Name** | A unique name for this animal. Every animal must have a name, and no two can share the same name. |
| **Sex** | Male, Female, or Unknown. |
| **Colors** | Click the color field to pick one or more coat colors. |
| **Weight** | Optional. Enter the weight in pounds. |

To add more animals, click **Add Another Puppy** (or Kitten). You can add up to 25 animals in a single litter intake.

To remove a row you added by mistake, click the trash icon on that row. You must always keep at least one row.

---

## Submitting the Litter

When all rows are filled in, click **Save Litter**. The system will:

- Create a record for each animal with all the shared information from Step 1.
- Assign each animal a unique ID automatically.
- If you enabled the protocol toggle, schedule the appropriate medical tasks (vaccinations, deworming, flea/tick prevention) for every animal.
- Link each animal to the mother if one was selected.

A confirmation message will appear showing how many animals were created. The new animals will appear immediately in your Animals list.

---

## Tips

- **Start with the mother.** If the mother isn't in the system yet, add her first as a regular intake so you can link the litter to her.
- **Use clear, distinct names.** The system won't allow duplicate names within the same batch, so each animal needs its own name.
- **Review before submitting.** All animals are created together as a group. If something goes wrong during creation, none of them will be saved, so you can fix the issue and try again without partial data.
- **Protocol is optional.** If you plan to set up medical schedules manually, turn off the protocol toggle in Step 1.
